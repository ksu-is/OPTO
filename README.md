# OPTO - Photo Storage Optimizer
#Project Overview
OPTO is a python photo storage optimizer that allows users to organize their photo libraries and free up their storage. I came up with this idea because i constantly have a bunch of pictures and no storage on my phone. I find myself having to pay more iCloud storage rather than going through the pictures i don't need anymore.
# Project Features: 
- Identify uplicated photos
- Analyze photo dates and their file size
- Recommend to delete older or less visited photos.
- Allow users to review the recommendations prior to deleting the images.
- Includes a "Don't show this again" option to identify pictures that want to be kept
- Eventually will be able to track how often users view a certain picture through OPTO
# Technology
- Python
- Pillow to help with image processing
- Hashlib to help identify duplicated images
- Github for version control
# Project Goals
  My goal with this project is to help people be able to manage their storage easier and save time and a bit of money. I want to begin with basic photo analysis and photo duplication detection, then eventually be able to add more advanced features to help track users interactions and being able to make personalized recommendations.
